DATA-DRIVEN STOCK MARKET PREDICTION

Utilizing LSTM, Random Forest, and NLP for Financial Forecasting

A Full Project Implementation Report

1. ABSTRACT

This project presents a comprehensive stock market prediction system that leverages the power of deep learning, ensemble machine learning, and natural language processing (NLP). By integrating historical price data from Yahoo Finance with real-time sentiment analysis of global news, the system provides a holistic view of market trends. The core implementation features a Long Short-Term Memory (LSTM) network for capturing sequential price patterns and a Random Forest Regressor for robust baseline comparisons. Furthermore, a specialized FinBERT model analyzes financial headlines to gauge the qualitative "mood" of the market, offering a unique multidimensional forecasting tool for retail investors.

2. INTRODUCTION

The stock market is a highly complex and dynamic system influenced by numerous factors ranging from economic indicators to political news and investor psychology. Traditional technical analysis often falls short because it ignores the qualitative impact of global news. This project aims to bridge that gap by building a platform that not only visualizes data but also predicts future outcomes using hybrid methodologies.

2.1 Project Objectives

  • To develop a real-time dashboard for tracking 100+ global stocks.
  • To implement time-series forecasting using LSTM (Recurrent Neural Networks).
  • To provide sentiment insights using Google's BERT architecture (FinBERT).
  • To simulate a trading environment for portfolio management.

4. RESEARCH METHODOLOGY

4.1 LSTM (Long Short-Term Memory)

Stock data is intrinsically non-linear and sequential. Unlike standard feed-forward networks, LSTM uses a "gated" architecture (Forget Gate, Input Gate, Output Gate) to decide which historical price movements are important. In this project, we use a 60-day window to predict the 61st day's price.

4.2 FinBERT for Sentiment Analysis

We utilize the ProsusAI/finbert model. FinBERT is a pre-trained NLP model specifically fine-tuned on financial corpora. It categorizes news headlines into Positive, Negative, or Neutral sentiments with significantly higher accuracy than generic sentiment models like VADER.

5. VIVA VOCE: FREQUENTLY ASKED QUESTIONS

Q1: What is the main USP (Unique Selling Proposition) of your project? The integration of qualitative analysis (News Sentiment) with quantitative forecasting (LSTM Price Tracking), providing a dual-layered insight that most basic stock predictors lack.
Q2: Why did you choose MongoDB instead of SQL? Financial data, especially news and watchlists, can vary in structure. MongoDB’s NoSQL architecture allows for easy scaling and flexible data schemas for various stock types.
Q3: What are "Vanishing Gradients" and how did LSTM solve it? In traditional RNNs, gradients get smaller as they propagate back through time, causing the network to "forget." LSTM solves this using a "constant error carousel" through its gate structure.
Q4: How do you handle the real-time nature of stock prices? We use Socket.io for live updates and a caching mechanism in our Stock Controller to prevent API rate limits from Yahoo Finance while keeping data fresh.
Q5: What is the significance of the `bcryptjs` library in your project? Security. We never store raw user passwords. Bcryptjs hashes the passwords before saving them to MongoDB, ensuring that even if the database is compromised, user accounts remain safe.
Q6: How does the model perform if the news is very volatile? While the price model might see a lag, the FinBERT sentiment model captures volatility immediately, shifting the "sentiment score" and warning the user of potential downward or upward pressure.
Q7: Can this system be used for High-Frequency Trading (HFT)? No, this is designed for retail swing and intraday analysis. HFT requires sub-millisecond execution and direct market access (DMA), whereas our system relies on public web-based data.
Q8: What is "Root Mean Square Error" (RMSE) in your evaluation? RMSE is a measure of the differences between values predicted by a model and the values observed. Lower RMSE indicates a more accurate price prediction.
Q9: Why use the `child_process.spawn` function in Node.js? To run Python ML scripts from our JavaScript backend. It allows us to pass real-time stock symbols to Python and receive JSON-formatted predictions back.
Q10: What is the future scope of this project? We plan to integrate actual Trading APIs (like Zerodha or Alpaca) for real-money execution and add advanced technical indicators like RSI and Bollinger Bands.

6. CONCLUSION

The project successfully demonstrates that while individual models have limitations, a hybrid system—combining historical mathematics (LSTM) with modern semantic understanding (NLP)—provides a superior analysis tool. The implementation of a real-time dashboard and portfolio simulation makes it highly practical for students and retail traders to learn the intricacies of the financial markets.
